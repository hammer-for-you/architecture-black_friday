### Задание 2. Шардирование

Запуск mongodb и приложения

```shell
docker compose up -d
```

Инициализация кластера шардов, реплик и серверов конфигурации

```shell
./scripts/mongo-init.sh
```

После того, как выполнился предыдущий скрипт, надо инициализировать роутер и наполнить БД данными.

```shell
./scripts/mongo-router-init.sh
```

Если при выполнении скрипта возникнет ошибка `MongoNetworkError: connect ECONNREFUSED 127.0.0.1:27020` - необходимо немного подождать, после чего запустить данный скрипт снова.
